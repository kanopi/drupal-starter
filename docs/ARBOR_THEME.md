# Arbor Theme

[kanopi/arbor](https://github.com/kanopi/arbor) is a Drupal subtheme built on
Ui Suite Bootstrap. It demonstrates integrations such as CKEditor 5 stylesheets,
negative margins in utility classes, and background gradients, and can be copied
and used as a template for creating your own subtheme.

Note that Arbor carries no backward compatibility policy — breaking changes can
happen at any time.

## Theme Commands

These commands should be prefaced with `ddev theme-npm`

Command | Description
--------|------------
`watch` | Watches the target folders and compiles SCSS on changes.
